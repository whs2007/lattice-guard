# 验证

## 触发
评审无阻断后进入。

## 必做

1. **跑仓库约定的测试命令**（`AGENTS.md` 或任务单里的 `test_cmd`），不要自己发明命令。
2. **跑一条人工可复现的路径**：按 `diagnosis.md` 的复现步骤走一遍，确认现象消失。
3. **UI / 交互改动**必须有同一气泡内的截图证据；纯逻辑改动可以只留命令输出。
4. **记录退出码**。非 0 就是失败，不许解释成「环境问题」。

## 产物 `ship-summary.md`

```
# 提测包 · <任务编号> <标题>

## 改动
- <文件>：<一句话>

## 实测
`<命令>` → 退出码 <n>（pass x / fail y）

## 检查
- 未改对外签名
- 未越出方案范围
- diff 仅 <n> 文件

## 人工优先看
<最该被人盯一眼的地方>

## 待批决策
- <自动决定 + 为什么需要追认>
```

> `verification/manifest.md` 由引擎生成，你不要写。

## 反例
- ❌「测试应该都能过」——没跑就是没验证。
- ❌ 只跑新增用例，不跑全量。
