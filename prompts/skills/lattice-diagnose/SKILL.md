# 诊断

## 触发
任务进入 `DIAGNOSE` 阶段时加载。

## 必做

1. **复现**：按任务描述走到现象出现的那一步。复现不了就写清楚卡在哪（环境、数据、权限），不许假装复现成功。
2. **定位**：从现象反推到具体代码位置。至少给出「文件 + 函数 + 行为假设」。
3. **取证**：每条结论后面挂证据——文件路径、行号、命令输出、测试名。没有证据的判断标 `（假设，待验证）`。
4. **划范围**：明确「这个 bug 涉及的代码边界」，以及**明确不涉及**哪些模块。

## 产物 `diagnosis.md`

```
# 诊断 · <任务编号> <标题>

## 问题如何复现
<步骤 + 复现命令>

## 根因在哪
<现象 → 机制 → 具体代码位置>

## 证据来自何处
- 代码：<路径:行号>
- 运行：<命令 + 输出摘要>
- 现象：<可量化的观测>
```

## 反例
- ❌「经排查是样式问题」——没有位置、没有证据。
- ❌ 顺手把修复方案写进来。诊断只诊断，方案是下一个技能的事。
